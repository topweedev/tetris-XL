投影模型對比 · Model 1 cell-center-fixed vs Model 2 scale-from-center

回答「正式 render 時方塊會不會一樣錯位」的問題。兩個模型並排，同樣的方塊佈局（Z=0 底層 + Z=1 兩個 piece + Z=10 active L），移除 xOff fudge，只看純投影效果。Model 1：cell center 固定，只有 size 隨 z 變大。Model 2（目前）：cell center 從 grid 中心向外 scale。

Model 2 分析Z=1 邊緣 cell 偏移 ~1.5px（中心 cell 完全對齊）。這是透視效果，非 bug。在 3D render 中，-5° tilt 會讓 Z=1 block 露出極薄的側面，加上深度環輔助，大腦會讀成「深度」而非「錯位」。Z=10 active 正確放大到 5.86x 並偏移到井口位置——這就是井道透視的核心。移除 xOff fudge 後，Z=1 偏移只剩 ~1.5px，非常細微。
